03 / Finding

HIGH / FINDING

SQL Injection

User-controlled input reaches a database query without sufficient parameterization or validation, allowing the query structure to be altered.

04 / Validation

The issue was validated in the authorized lab environment by observing how the application handled crafted input and comparing the resulting responses.

05 / Remediation

Use parameterized queries or prepared statements, validate input according to its expected type, and apply least-privilege permissions to the database account.
